# 🎂 Maria's 43rd Birthday Website

A beautiful, responsive birthday celebration website for Maria's 43rd birthday.

## Features

✨ **Responsive Design** - Works perfectly on mobile, tablet, and desktop
💖 **Glassmorphism UI** - Modern frosted glass effect with blur
🎨 **Gradient Background** - Romantic pink gradient theme
📸 **Photo Gallery** - Display beautiful memories
💬 **Personalized Message** - Heartfelt birthday wishes in German
🎉 **Animations** - Pulsing hearts animation

## Live Website

Visit: https://iammiracle06-max.github.io/maria-birthday/

## How to Use

1. Add your photos to the repository:
   - `maria1.jpg` - Main profile photo
   - `maria2.jpg` - Gallery photo

2. Customize the message in `index.html` if needed

3. The website will automatically deploy via GitHub Pages

## Customization

Edit `index.html` to:
- Change the greeting message
- Modify colors in the CSS
- Add more photos to the gallery
- Update the button link
